# Project Memory (Índice)

## Core
- Contato estritamente via WhatsApp. Sem números de telefone ou links `tel:`, sem e-mail (`mailto:`), sem exibição visível do número do WhatsApp — todo CTA passa pelo funil global.
- Estética "SaaS Premium": tipografia limpa, glassmorphism, sem temas "Cyberpunk" pesados.
- SEO Evolutivo: nunca remova páginas/URLs existentes.
- Foco em dominar o SEO local de Curitiba e conversão via funil de WhatsApp.
- Carregamento "Instantâneo": uso de shell estático e estratégia agressiva de performance.
- `sitemap-news.xml` é gerado automaticamente por `scripts/generate-rss.mjs` (predev/prebuild) — nunca editar à mão.
